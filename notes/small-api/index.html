小接口

上个月给内部工具补了一个接口。需求单上写了八项，真正上线的只有三件：创建、查询、取消。

剩下的五项都是「以后可能要用」。先不写。字段一旦出现在响应里，调用方就会依赖它。

这三件

  • 创建：只收标题、日期和负责人。
  • 查询：按日期倒序，一次最多二十条。
  • 取消：不删记录，只把状态改成已取消。

错误也只有两种。参数不对，返回 400，正文写明哪个字段。下游超时，返回 503，不把堆栈塞进响应。

等真的有人要筛选和导出，再加路由。现在这个文件还不到两百行。
