这个站重新开始

原先这里是 Hexo 的默认主题。现在改成阅读向的个人主页：名字和导航在上，笔记按时间排在下面。

原先打开这个站，看到的是 Hexo 默认主题：标题是 Hexo，页脚是 John Doe，正文是 Hello World。那个页面不能代表这里。

现在改成阅读向的个人主页。版式参考图拉鼎的 imtx.me：顶栏放名字和导航，下面用分类进入笔记和项目，文章按时间排列，点进去是一栏正文。

目前公开的页面是这些：

  • Notes，从这篇文章开始。
  • Learning，对应 GitHub 上自己建立的 tech_learning。
  • About，只写公开资料里能核对的部分。

GitHub 上其余仓库是 fork，包括云原生笔记、CS-Notes、Nacos 和 Netty。它们留在仓库列表里当阅读材料，不写进「主要作品」。

新的笔记不用再改 HTML。打开后台，用 Markdown 写完保存，会提交到 GitHub。
